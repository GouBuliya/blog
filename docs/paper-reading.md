# 论文阅读数据与验收

## reading.json

每篇论文在 `paper-translations/<id>/`（其他本地译本在原有子目录）提交 `reading.json`。它是章节目录的唯一来源，浏览器不解析 PDF 书签。不得用“封面、正文”占位替代实际章节。

```json
{
  "version": 1,
  "pdfSha256": "替换为中文PDF的64位小写SHA256",
  "outline": [
    { "title": "引言", "page": 1, "level": 1, "y": 0.32 },
    { "title": "方法", "page": 3, "level": 1, "y": 0.08 },
    { "title": "模型结构", "page": 3, "level": 2, "y": 0.41 }
  ],
  "original": null
}
```

- `page` 是从 1 开始的物理 PDF 页码，不是印刷页码。
- `y` 是标题在页面上的纵向位置，从页面顶端算：0 为顶端，1 为底端。PDF 书签里的坐标是从页面底端往上算的，直接抄过来会让每次跳转都落到上下镜像的位置。
- `level` 为 1–6。目录至少覆盖正文各节、参考文献及附录。
- 双栏论文按阅读顺序排列条目，不按 `y` 排序。

中英对照使用本地 `paper.en.pdf`，以避免跨域与远程嵌入限制。`original` 为 `{ "file": "<id>/paper.en.pdf", "pages": 20, "sourceUrl": "https://arxiv.org/pdf/<id>v1", "sha256": "64位哈希", "outline": [...] }`，路径相对 `paper-translations/`。应使用与译文对应的原文版本，保留准确来源 URL。带中英对照版 PDF 的论文另需 `dualOutline` 和 `dualSha256`。已知问题写在 `notice` 字段，读者首次打开时会看到；空白或损坏的页面不能靠填造文字补上。

不要把本机绝对路径写入公开 metadata；本地 catalog 与源码 ZIP 不提交。

## 起草与校正目录

```sh
npm run papers:outline                # 报告每篇会改什么，不写入
npm run papers:outline -- 2609.36529  # 只看指定论文
npm run papers:outline -- --write     # 写入
```

工具读取 PDF 书签，对译文、原文、对照版分别处理：目录为空则用书签填入；目录与书签逐条、逐页对得上则只校正 `y`，标题和层级保持原样；其余视为手工编写，不改动。新论文需先建好带哈希的 `reading.json`。结果只是初稿：没有书签的 PDF 要从正文手工补齐，写入后在阅读器里逐条点一遍。替换译本后应重新核对，而不只是更新哈希。

## 发布检查

`npm run papers:sync` 和 `npm run build` 都会检查：必填项与取值范围；PDF 哈希与 `reading.json` 一致；页数一致；目录与书签逐条对得上时，`y` 与书签位置相差不超过 0.03，否则报错并指出是哪一条。最后一项能拦住上下颠倒的目录，但管不到没有书签的 PDF 和手工重排过的目录。

## 阅读器的行为

- 页面大小：默认“适合正文”，按前几页文字的左右边界裁掉页边距，手机上字号约为整页宽度时的 1.4 倍。可在菜单里改为“整页宽度”，选择会记住。
- 位置：记为“第几页 + 页内纵向比例”，写作 `page=4&y=0.42`，与缩放和屏幕无关。本地保存与链接共用这一格式，链接形如 `…/read/#page=4&y=0.42`，原文加 `?file=original`。链接里的位置只生效一次，之后刷新回到上次读到的地方。
- 跳转与返回：点目录、点 PDF 内部链接、输入页码、文内查找之后，底部出现“回到第 N 页”，可逐级返回。
- 中英对照：桌面并排显示，默认同步滚动；手机上是切换语言。两种语言之间按章节对应位置。只有两份目录条数相同、层级基本一致时才能按章节对应，否则退回按全文比例，位置会有偏差。
- 文内查找：Ctrl/⌘ F 或工具栏。从列表页的搜索结果进入时会带上查询词并高亮。
- 放大：在页面上直接框选图表或公式，按屏幕分辨率从 PDF 重新渲染，再放大仍然清晰。
- 复制：照常复制即可，剪贴板里是合并了排版断行的段落；段落按行的位置推断，公式仍以 PDF 为准。可在菜单里关闭。

## 全文检索

构建时提取全部页面的文字，译文和原文各输出一个索引：`paper-search.zh.json`、`paper-search.original.json`。列表页的搜索框同时筛标题和搜正文，首次搜索时才下载译文索引，勾选“同时搜索英文原文”才下载原文索引。查询先按整句匹配，找不到再拆成词。结果按论文归组，链接到对应语言和页码。跨行断开的英文单词在索引里已接回。

扫描件可提供经过核对的 `search-text.json`，内容为按物理页码排列的字符串数组。Metis 历史译本存在正文空白页，目前保留原文件并提供英文版。

## 提交前

运行 `npm test`、`npm run papers:sync` 和 `npm run build`。在桌面与手机宽度下验证：目录逐条跳转后标题在屏幕顶部；PDF 内部链接与返回；刷新恢复位置；带位置的链接在另一种屏幕宽度下打开到同一处；对照并排与同步滚动；手机切换语言后位置对应；框选放大；复制成段；列表页搜索命中正文并打开到正确页码。浏览器禁用存储或剪贴板时，阅读与手动复制仍应可用。
