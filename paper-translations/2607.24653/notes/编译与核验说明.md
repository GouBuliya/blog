原文：Kimi Team, Kimi K3: Open Frontier Intelligence，arXiv:2607.24653v2（2026-08-07 修订）。
https://arxiv.org/abs/2607.24653v2

正文、附录、摘要、章节标题、图表说明、脚注及解释性算法文字均已翻译。原有论证顺序与技术内容保留；没有增添译者评论。25 个 TeX 文件中修改了 17 个，另 8 个为作者名单与图形主体，按原样保留。作者与机构姓名、参考文献、图内文字、表格单元格和约定技术术语保留原文。

## 文件

- `main.tex`：中文主文件。
- `_original/`：未修改的原始源码与资产。
- `_source.tar.gz`：从 arXiv 下载的源码包。
- `references.bib`：原始参考文献，字节未改。
- `references-compat.bib`：供 BibTeX 使用的兼容副本，仅去掉注释行，并将一处月份 `Nov` 规范为 `11`。
- `main.bbl`：已生成的参考文献。
- `.latexmkrc`：Unicode BibTeX 与长作者字段的编译设置。
- `checks/`：公式与结构比对、漏译检查及编译日志。

## 编译

需要 XeLaTeX、latexmk、bibtexu 及完整 TeX Live（含 ctex、pgfplots、biblatex）。在源码目录执行：

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex
```

本次在 macOS 上用系统 Perl 调用 latexmk：

```sh
/usr/bin/perl /opt/homebrew/bin/latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex
```

为兼容 XeLaTeX，主文件使用 ctex 替换原 CJKutf8，保留原 `chinese` 宏接口，显式中文化摘要、图表和算法名称；正文行内数学使用 `\(...\)`。三个较宽的表格仅增加限宽外框，表格数据及内部结构未改。

原环境无法运行 Biber，因此本译本使用 Unicode BibTeX 后端。原始 `.bib` 保留，兼容副本供编译使用。参考文献仍为数字引用，编号由当前后端生成，文内引用与文末条目对应。
