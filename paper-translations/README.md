# 中文论文译本归档

收录 36 篇已有 LaTeX 译文的论文，以及 5 篇来源尚未核实的其他本地译本。文件从原位置复制，原文件未移动。此次只做本地归档，尚未发布到博客。

每篇以论文编号建立目录，`paper.zh.pdf` 为优先展示的译本，`source.zip` 为源码包，`notes/` 保存已有说明。不同内容的旧 PDF 和配套源码保留在 `versions/`；同字节副本仅在来源记录中列出。`catalog.json` 与各目录的 `metadata.json` 记录原位置、页数、SHA-256 和文件路径，可作为后续 paper list 的数据来源。

此次已检查复制前后 SHA-256、PDF 可打开及 ZIP CRC；未重新编译全部历史论文，也未重新审校翻译质量。无原始校验说明的译稿不能据此次归档认定为全文审校通过。RCDL 和神经网络对偶形式沿用原有双篇联合源码包。
