# LSA 中文全文

原论文：Ales Kubicek等，*Latent Sparse Attention: Towards Subquadratic Ultra-Long Context Attention*。
本译稿依据arXiv:2610.42147v2（2026-11-03），制作日期为2026-11-04。
原文：https://arxiv.org/abs/2610.42147v2
用户提供的阅读链接：https://www.alphaxiv.org/pdf/2610.42147

## 文件与编译

- `main.pdf`：30页中文全文。
- `main.tex`：主文件，保留原文的正文和附录结构。
- `algorithms/`：5个算法；`tables/`：12个表格；`plots/`：原始图形。
- `preambles/`：包和宏；`main.bib`、`main.bbl`：原始参考文献。
- `_original/`、`_source.tar.gz`：未改动的原始源码及下载包。
- `validation/`：源码保留核对、漏译检查和编译日志。

在本目录执行：

```sh
sh build.sh
```

需要XeLaTeX、ctex、TeX Gyre字体及原模板依赖的TeX包。构建默认读取原始`main.bbl`，不重生成参考文献。若修改了引用或`main.bib`，先运行一次XeLaTeX，再运行`bibtex main`，然后执行构建脚本。`.latexmkrc`默认禁止自动重生成书目，以保留原始版本。

## 翻译范围

完整翻译标题、摘要、正文、图表caption、脚注、致谢、全部附录，以及算法中的解释性自然语言、输入输出说明、阶段标题和注释。保留了D-LSA Flat/Tree与N-LSA的区别、实验条件、失败结果、100M-token外推限定，以及原生训练的模型规模和上下文长度限制。

按translate-paper-latex技能约定，以下内容保留英文：数学表达式及其中的文字，图片内部标签，表头和表格单元格，参考文献条目，作者与机构名，代码标识符，算法关键词，以及技术名称。表格中的说明文字也按原表保留；算法中用于排版输入说明的tabular则翻译其自然语言。

正文行内公式统一使用`\(...\)`，无编号块级公式使用`\[...\]`；编号公式环境保持不变。为满足公式内容逐字保留，公式内部`\text{...}`中嵌套的数学界定符保留原样。
