原文为 *Understanding Transformer from the Perspective of Associative Memory*，arXiv:2505.19488v1，作者为Shu Zhong、Mingyu Xu、Tenglong Ao和Guang Shi。本译本使用作者提交的LaTeX源码，翻译正文、附录、图注与解释性代码注释，并保留associative memory、memory capacity/update、attention、Delta Rule、kernel、key/query/value、state tracking等英文术语。

公式内容、引用、图像、表格本体和程序标识符按原文保留。数学分隔符统一为行内 `\(...\)`、块级 `\[...\]`；为XeLaTeX中文编译调整模板与字体，必要时仅调整公式换行和页面布局。源码中的 `sections/relatedwork.tex` 已翻译，但原始主文件没有引入它，译本沿用原始章节结构。

本文包含作者的理论解释、实验观察和探索性猜想。翻译保留原有论断的强弱；下面列出阅读与复用时需要注意的原文问题，不将它们作为已修正的结论。

## 原文中的数学与论证疑点

- **SNR推导**：附录 `sec:exp_kernel` 的一个等号将key平方范数从指数外移到指数内，两式一般不相等。SoLU的最后一步近似省略了常数因子 \(e^2\)。用key范数的期望替代随机范数、将 \(N-1\) 写作 \(N\)，均是原文使用的近似；降低温度改善检索的结论也有适用区间。MQA的噪声方差缩减需要head之间的独立性或协方差条件。
- **一般优化目标**：要求 \(A_t\) 与 \(B_t\) 分别对称，是使线性算子自伴的充分条件，原文将其写成必要条件过强，例如二者均反对称也可满足自伴性。Linear Attention与Softmax Attention的gating目标中出现“对角矩阵乘Frobenius范数平方”，与标量目标的类型不一致；后者的系数也未与前述更新矩阵一致对应。DeltaNet momentum目标的求和仍使用当前时刻的key/value下标，未反映展开式中的历史下标。
- **Kernel形式与复杂度**：附录Delta Rule推导的末式混用了 \(f\) 和 \(\phi\)。无限维feature map并不能直接保证有限维 \(O(d^2)\) 推理成本，需说明可计算表示或近似。原文对标准softmax attention的 \(O(1)\) 训练时间描述，应结合并行计算口径理解，不能当作总运算量。
- **State exchange定理**：定理正文写 \(f(k_i^\top k_i)=0\)，与单位范数以及假设要求的 \(f(1)=1\) 冲突；\(\epsilon(d,n)\) 和 \(\epsilon(n,d)\) 的参数顺序也不一致。四个离散点的插值不等于在各点邻域内精确实现round函数，因此原文用四个指数kernel的组合满足假设2的论证尚有缺口。球面编码构造给出对数维度的可行方案，原文将其表述为必需条件需进一步论证。\(O(n\log n)\) 空间结论还需交代value维度和存储精度。
- **电路复杂度**：\(TC^0\) 不意味着每个输出只依赖常数大小的输入邻域。\(TC^0\) 与 \(NC^1\) 的严格分离尚未证明，因此基于此宣称严格表达能力分离需要注明条件；实验优势本身不能补足这一证明。
- **解析解与无限上下文**：附录最优memory矩阵的逆矩阵表达需要相应矩阵可逆；正文低秩情形的伪逆化简一般不成立。由无限上下文推导SGD收敛、再推导整个网络退化为bigram模型，需要步长、数据分布等条件，不能脱离这些条件视为普遍结论。
- **图任务与记号**：实验中用floor符号表示保留两位小数的round操作，定义已在原图注说明，它不同于通常的向下取整。原文将球面向量问题称为“Thompson problem”，名称与具体问题对应关系需核实。对于按拓扑顺序排列的有限DAG，邻接矩阵幂零，逆矩阵的有限几何级数关系可为精确等式；原文称其为近似，译文沿用原述。

## 示例代码的使用边界

附录代码作为原文示例保留，未将其改写为经过复现验证的软件。Chunkwise伪代码中的单位矩阵构造多一次 `unsqueeze`，中间张量默认设备与输入设备可能不同，也没有处理长度不能整除chunk大小的尾部。示例将 `num_kv_heads` 的默认值保存到成员变量后，部分投影层仍使用原始参数，传入 `None` 时可能失败。使用这些代码前，应独立验证张量形状、设备、边界和数值行为。
