# 深度选择性状态空间模型的理论基础：中文全文

原文：Nicola Muca Cirone、Antonio Orvieto、Benjamin Walker、Cristopher Salvi、Terry Lyons，*Theoretical Foundations of Deep Selective State-Space Models*。

依据[arXiv:2402.19047v4](https://arxiv.org/abs/2402.19047v4)（2025-01-06更新），2026-11-08获取并翻译。用户提供的链接为https://www.alphaxiv.org/abs/2402.19047。

## 文件与编译

- `main.pdf`：39页中文全文。
- `main.tex`：正文和全部附录。
- `math_commands.tex`：正文使用的宏与定理环境；`defs.tex`：源包附带的另一套定义文件，未由主文件载入。
- `img/`、`main.bib`、`main.bbl`和样式文件：原始资源。
- `_original/`、`_source.tar.gz`：未改动的原始源码及下载包。
- `validation/`：保留审计、漏译报告、原文CJK基线日志、中文编译日志和独立重编译结果。

在本目录执行`sh build.sh`。需要XeLaTeX、ctex、Fandol和TeX Gyre字体及原模板依赖。脚本使用原始`main.bbl`，不重新生成书目。若修改参考文献，可手动运行BibTeX后再编译。

## 翻译范围

完整翻译标题、摘要、正文、图注、普通脚注、致谢、定理/命题/定义/推论、证明文字，以及附录A至F：路径签名简介、表达能力、对角系统的稳定性与串联、路径到路径、Wronskian矩阵理论、ZOH与精确解。3个TeX文件均有中文化修改，其中正文和附录集中在主文件，另外两个文件中文化定理环境名称。
