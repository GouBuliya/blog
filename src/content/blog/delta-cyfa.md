*时间定位置，Delta 定绑定，海绵定寿命——一次从公理出发的完整推导*

## 0. 引子：一个记忆应该遵守什么规律

CyFA（Cyclic Flow Attention）是一个把记忆按"年龄"组织起来的线性 RNN：每个 head 维护一个 127 格的环形缓冲区，新 token 写在年龄零，旧内容随一个可学习的时钟往年龄更大的方向流动，读出时在 127 个年龄桶上做 softmax。它的成绩很有特点：在"从一篇长文档里抽一个事实"这类任务上，400M 时比最好的循环模型高十几分；在 few-shot 这类任务上，却比 KDA 低十五分。

这两类任务的差别在哪？前者的 key 基本互不相同，每个事实只出现一次；后者是几百个格式一样的样例，"Question:"、"Answer:"、标签词反复出现。CyFA 擅长的是**按时间找**，few-shot 需要的是**在重复中按内容找**。

笔者想做的不是给 CyFA 打补丁，而是问一个更基本的问题：**一个按时间组织的记忆，应该遵守什么规律？** 把规律写成几条公理，然后让公理决定架构长什么样。本文沿着三个问题推进：

1. 记忆在时间里演化时，应该满足什么一致性？答案给出指数衰减和积分写入，并说明 CyFA 是它的一阶近似。
2. 存进去的东西怎样才能被忠实地找到？两条召回公理给出 key 侧的 delta 法则，连同输运和衰减一起有精确解。
3. 走完一圈的旧内容怎么办？点状的 sink 在带限的环上会出现 Zeno 效应，正确的做法是一层海绵。

三个答案合起来就是本文的架构，笔者叫它 Delta-CyFA。一句话概括：**时间定位置，Delta 定绑定，海绵定寿命。** 推导的每一步都用数值实验核对过，包括一次走错的路——那次失败教会我们什么能做、什么不能做，所以也写进来了。

本文自包含。数学上只用到矩阵指数和一阶线性微分方程，会在用到的地方从标量情形讲起。

## 1. 基本回顾：CyFA 在做什么

CyFA 的每个 head 维护两张 m×d 的矩阵 K\_t 和 V\_t，m 是槽的数量，论文取 127。每来一个 token，两张矩阵经历同样的三步：沿槽维度循环平移 δ\_t 格、整体乘以遗忘门 α\_t、在"年龄零"的位置加上一行新内容：

\[
K_t=\alpha_t\,P(\delta_t)\,K_{t-1}+\beta_t\,e_0k_t^{\top},\qquad V_t=\alpha_t\,P(\delta_t)\,V_{t-1}+\beta_t\,e_0v_t^{\top}
\]

e\_0 是第 0 个槽的 one-hot 向量，β\_t 是写入门，δ\_t 是时钟增量，由输入决定，取值在 (0,1) 之间，并且对输入做了 stop-gradient。累计时钟 τ\_t = δ\_1 + … + δ\_t 定义了"记忆时间"，一个历史 token i 到现在的年龄是 τ\_t − τ\_i，不一定等于 t − i。

**分数平移。** δ\_t 不是整数，所以 P(δ) 不是普通的置换矩阵。CyFA 在实 Fourier 基底里定义它：把 m 维向量分解成一个直流分量和 (m−1)/2 个二维旋转块，频率 ω\_j = 2πj/m，平移 δ 就是让第 j 个块旋转 ω\_jδ。这样定义的 P 满足

\[
P(a)P(b)=P(a+b),\qquad P(1)=\text{整数循环移位},\qquad P(s)=e^{sJ},\ J^{\top}=-J
\]

这也是 m 取奇数的原因：偶数 m 会多出一个没有配对的 Nyquist 频率，实数旋转块凑不齐，P(1) 的行列式是 −1，不在任何反对称矩阵的指数像里。还要记住一点：e\_0 在这个基底里不是一个"点"，而是一个 Dirichlet 核——宽约一格、两侧带旁瓣。两个分数位置的带限脉冲之间的内积在相距半格时是 0.64，相距 0.9 格时是 0.11，相距整数格时为零。后面很多事情都和这个数字有关。

**读出。** 查询 q\_t 先和 key 状态作用得到 m 个槽分数，softmax 之后用这个分布去加权 value 状态：

\[
o_t=(RV_t)^{\top}\,\mathrm{softmax}\!\big(RK_tq_t\big)
\]

R 是一个可学习的 m×m 矩阵，初始化为单位阵，只出现在读出里，不参与状态更新。softmax 是在**槽**上做的，不是在 token 上做的——这一点决定了 CyFA 能做什么、不能做什么。q、k、v 在投影之后都过了一个 ShortConv，所以 key 里天然带着前几个 token 的信息，第 6 节会用到。

**Absolute-clock 坐标。** 直接按上面的式子算，每步都要对状态做一次平移，很贵。CyFA 的关键技巧是换坐标：令 K̄\_t = P(−τ\_t)K\_t，利用 P(−τ\_t)P(δ\_t) = P(−τ\_{t−1})，递归变成

\[
\overline{K}_t=\alpha_t\,\overline{K}_{t-1}+\beta_t\,\overline{b}_t\,k_t^{\top},\qquad \overline{b}_t=P(-\tau_t)\,e_0
\]

状态本身不再动，平移被转嫁到写入向量 b̄\_t 上，而 b̄\_t 在 Fourier 基底里就是一组旋转因子，每个 token 算一次即可。于是递归是"标量衰减 + 秩一写入"，可以用现成的线性注意力核做 chunk-wise 并行。读出也相应地换坐标：先把 K̄\_t q\_t 转回物理槽空间做 softmax，再把槽分布转到 absolute 坐标去读 V̄\_t。这个"两遍线性注意力、中间夹一个 softmax"的结构，本文自始至终保留。

在 absolute 坐标里有一个直观图像，后面会反复用到：**存进去的内容是静止的，动的是写入头。** 写入头在环上以时钟的速度转，每个 token 的内容留在它被写下的那个位置。

## 2. 记忆时间：连续时间的视角

P(δ) 是一个单参数群，P(s) = e^{sJ}。这意味着平移不必看成"每个 token 跳一下"，而可以看成记忆时间 τ 里的连续流动 dK/dτ = JK。既然时间是连续的，就可以提一个要求。

**时间分段一致性。** 记 F\_δ(M) 为同一个恒定输入驱动下，记忆经过 δ 单位时间的变化。先走 a 再走 b，应该等于一口气走 a+b：

\[
F_b(F_a(M))=F_{a+b}(M)
\]

这是半群性质。它说的是：同一段连续动力学的结果，不应该依赖我们怎么划分计算步长。这个要求能推出什么？

**衰减必须是指数。** 设经过 δ 时间的保留率是 α(δ)，一致性要求 α(a+b) = α(a)α(b)，加上 α(0) = 1 和连续性，唯一解是 α(δ) = e^{−γδ}。CyFA 的遗忘门 α\_t 可以写成 e^{−γ\_tδ\_t}，其中 γ\_t = −ln α\_t/δ\_t 是"每单位记忆时间的遗忘速率"，这只是改写，不损失一般性。如果进一步要求 γ 是常数，衰减就完全由时钟决定；本文不强求这一点，把它留作一个变体。

**朴素瞬时写入不满足一致性。** 把写入也按时间分段：一步写 η(a+b)e_0zᵀ，和分两步各写 ηa、ηb，差别在于第一次写入的内容会在第二段里被再平移、再衰减一次，而一次写入的不会。这里否定的是这种简单的「步长乘以固定 one-hot」写法，而非一切离散写入公式——事实上，下面的精确积分写入本身就给出了满足半群性质的离散公式。出路是先让写入在连续时间里发生，再求精确离散化：

\[
\frac{dM}{d\tau}=(J-\gamma I)\,M+\eta\,e_0z^{\top}
\]

这是一阶线性非齐次方程。记 A = J − γI，常数变易法给出

\[
M(\tau+\delta)=e^{A\delta}M(\tau)+\eta\int_0^{\delta}e^{As}e_0\,ds\;z^{\top},\qquad e^{A\delta}=e^{-\gamma\delta}P(\delta)
\]

定义积分写入轮廓 h\_γ(δ) = ∫₀^δ e^{−γs}P(s)e\_0 ds。它是把 token 的内容沿这一步经过的整段记忆时间铺开，而不是瞬间放在年龄零。它满足精确的组合律

\[
h_{\gamma}(a+b)=e^{-\gamma b}P(b)\,h_{\gamma}(a)+h_{\gamma}(b)
\]

代回去就能验证 F\_b∘F\_a = F\_{a+b}。在 Fourier 基底里它有闭式：第 j 个频率上是 ê\_0(ω\_j)(1 − e^{−(γ+iω\_j)δ})/(γ+iω\_j)，不需要数值积分。换到 absolute-clock 坐标后还有一个更省的算法：

\[
\overline{h}_t(\omega_j)=\frac{\overline{b}_t(\omega_j)-e^{-\gamma\delta_t}\,\overline{b}_{t-1}(\omega_j)}{\gamma+i\omega_j}
\]

新的写入向量是相邻两步旧写入向量的差，除以一个常数。没有新增的超越函数。

**三点评注。** 第一，δ → 0 时 h\_γ(δ) ≈ δ·e\_0，正是 CyFA 的 one-hot 写入乘以 δ，所以 CyFA 是这个流的一阶 Euler 近似；(1−e^{−z})/z 型的修正正是 Mamba 一类模型的 ZOH 离散化，这里得到的是它在循环槽空间上的版本。第二，积分写入在 δ < 1 时只是亚槽宽度的平滑：ω\_jδ/2 < π/2，sinc 因子不低于 0.64，没有零点，所以它对原始 CyFA 的改动是温和的。第三，这一节给出的是一个框架——从此以后，任何新机制都写进这个方程，解出来，再离散。下面两节各加一项。

## 3. 召回公理与 Delta 法则

第 2 节处理的是记忆如何演化，这一节处理记忆如何被找到。先把 CyFA 的递归展开，看看状态里到底存了什么：

\[
K_t=\sum_{i\le t}w_{t,i}\,P(\tau_t-\tau_i)\,e_0\,k_i^{\top},\qquad w_{t,i}=\beta_i\prod_{j=i+1}^{t}\alpha_j
\]

第 i 个 token 的 key 被存在它当前年龄对应的槽轮廓上，权重是写入门乘上此后所有遗忘门的积。整个状态是"槽轮廓 × key"外积的叠加，这是经典的 Hebbian 关联存储。两张矩阵于是是两个线性映射：K\_t 把 key 映到年龄，V\_tᵀ 把年龄映到 value。一个忠实的记忆应该满足：

**公理一（key → 年龄）**：用存过的 key 去查，返回它被存入的年龄。

**公理二（年龄 → value）**：读某个年龄，返回当时写入的 value，不混进别的内容。

用存过的 key k\_j 去查加性存储：

\[
K_t\,k_j=\sum_{i\le t}w_{t,i}\,(k_i\cdot k_j)\,P(\tau_t-\tau_i)\,e_0
\]

要只剩 i = j 那一项，所有交叉项 k\_i·k\_j 必须为零——key 两两正交。每个 key 只出现一次时，交叉项是方向随机的小扰动，softmax 还能把正确的槽挑出来；同一个 key 反复出现时，交叉项全是大正数，返回的是所有出现年龄的叠加。Few-shot 模板里 "Answer:" 出现 500 次，查它得到 500 个年龄的和，softmax 的质量被模板 token 吸走，携带信息的 token 反而拿不到权重。这就是公理一在 CyFA 里失效的方式。公理二的失效方式是年龄混叠：读年龄 s 时，年龄 s+m、s+2m 的内容落在同一个槽里。这一节处理公理一，公理二留到第 8 节。

**从求和到最小二乘。** 加性写入的问题在于只加不减。换一个角度：不规定"怎么写"，而规定"写完之后状态应该满足什么"。公理一说写完 k\_t 之后应该有 Kk\_t = e\_0。写成目标函数并求梯度：

\[
L(K)=\tfrac12\|Kk_t-e_0\|^2,\qquad \nabla_KL=(Kk_t-e_0)\,k_t^{\top}
\]

沿负梯度走一步，步长 η：

\[
K\;\leftarrow\;K-\eta(Kk_t-e_0)k_t^{\top}=K\,(I-\eta\,k_tk_t^{\top})+\eta\,e_0k_t^{\top}
\]

这就是 Delta 法则，"delta" 指更新量正比于误差。拆开看是两个动作：右乘 (I − ηk\_tk\_tᵀ) 把 K 在 k\_t 方向上的分量削掉——"当前 k\_t 指向哪些年龄"被抹掉；再加上 ηe\_0k\_tᵀ，把 k\_t 指向年龄零。η = 1/‖k\_t‖² 时擦除是完全的，更新后 Kk\_t = e\_0 精确成立。熟悉 DeltaNet 的读者会认出这正是它的 S ← S(I − βkkᵀ) + βvkᵀ，区别只在目标：DeltaNet 是 key 到 value，这里是 key 到年龄。

**顺序问题。** DeltaNet 的状态在两次写入之间是静止的，CyFA 的状态在两次写入之间还要平移。擦除方向在 key 空间，平移在槽空间，离散地写下来就有顺序问题：先擦再移再写，还是先移再擦再写？不同顺序差一个 O(δ) 的项，而且没有哪个顺序是"对"的。第 2 节的框架正是为此准备的：不在离散层面纠结顺序，把擦除、平移、衰减、写入四件事放进同一个连续方程，让它们同时发生，精确求解之后再看离散更新长什么样。

## 4. Key 侧的精确解：两套时间

先用一个标量热身。一个数 u 以速率 γ 衰减、以速率 κ 被擦除、以速率 η 被写入：du/dτ = −(γ+κ)u + η，两边乘积分因子 e^{(γ+κ)τ}，左边凑成全导数，积分得到

\[
u(\delta)=e^{-(\gamma+\kappa)\delta}u(0)+\eta\,\frac{1-e^{-(\gamma+\kappa)\delta}}{\gamma+\kappa}
\]

两个观察：对旧内容来说衰减和擦除在指数上相加；写入项的分母也是 γ+κ，因为新写进来的东西在写入的同时也在被擦除。矩阵情形的全部结构都在这里了。

**第一次写法，和它的问题。** 最直接的做法是把擦除项加进第 2 节的方程：dK/dτ = (J−γI)K − ηKk\_tk\_tᵀ + ηe\_0k\_tᵀ。解出来擦除的比例会是 1 − e^{−κδ\_t}，κ = η‖k‖²——擦除剂量 = 速率 × 记忆时间。这看起来很优雅，却有一个致命的冲突：few-shot 的模板词恰恰是时钟应该压缩（δ 小）、绑定又必须覆盖的 token。笔者做了一个小实验，key A 出现在每个 4-token 样例的开头，共 12 个样例，最后用 A 去查：

| 设定 | 最近一次的分数 | 上一次的分数 | softmax 落在最近一次的质量 |
| --- | --- | --- | --- |
| 剂量绑时钟，δ\_A = 1 | 0.87 | 0.03 | 0.99 |
| 剂量绑时钟，δ\_A = 0.1 | 0.27 | 0.31 | 0.20 |
| 剂量独立，ε = 3，δ\_A = 0.1 | 0.87 | 0.03 | 0.99 |

时钟一压缩模板词，"指向最近一次"这个性质就没了。结论是剂量不能绑在时钟上。

**两套时间。** 出路是承认每个 token 有两套时间：记忆时间 τ 驱动输运和衰减，走 δ\_t；token 内部的"学习时间" s ∈ [0,1] 驱动梯度流，剂量 ε\_t 由 token 自己决定。方程写在 s 上：

\[
\frac{dK}{ds}=\underbrace{\delta_t\,(J-\gamma_tI)\,K}_{\text{输运与衰减}}\;\underbrace{-\;\varepsilon_t\,K\,\hat k_t\hat k_t^{\top}}_{\text{擦除}}\;+\;\underbrace{\eta'_t\,e_0k_t^{\top}}_{\text{写入}}
\]

记 A = δ(J−γI)，B = −εk̂k̂ᵀ，C = η′e\_0kᵀ，方程是 dK/ds = AK + KB + C。A 从左边乘，B 从右边乘。

**求解。** 关键事实：左乘和右乘互相交换，A(KB) = (AK)B。所以齐次解是 e^{As}K(0)e^{Bs}，求导验证：乘积法则给两项，一项用 A 与 e^{As} 交换，一项用 B 与 e^{Bs} 交换。非齐次解照抄标量情形的结构，"常数项在时刻 u 注入然后演化到 1"累加起来，Leibniz 法则验证即可：

\[
K(1)=e^{A}K(0)e^{B}+\int_0^{1}e^{Au}\,C\,e^{Bu}\,du
\]

三个指数分别算。e^{A} = e^{−γδ}P(δ)，因为 I 和 J 交换。e^{Bu} 是秩一矩阵的指数，k̂k̂ᵀ 是投影，任意次幂都是自己，幂级数坍缩成 e^{Bu} = I + (e^{−εu} − 1)k̂k̂ᵀ：作用在 k̂ 上乘 e^{−εu}，作用在垂直方向上不动。于是 Ce^{Bu} = η′e\_0kᵀ[I + (e^{−εu}−1)k̂k̂ᵀ] = η′e^{−εu}e\_0kᵀ，用了 kᵀk̂k̂ᵀ = kᵀ——被写入的 key 恰好在被擦除的方向上，所以写入项自己也按 ε 衰减。积分只剩

\[
\int_0^{1}e^{Au}Ce^{Bu}du=\eta'\int_0^{1}e^{-\varepsilon u}e^{-\gamma\delta u}P(\delta u)\,e_0\,du\;k^{\top}=\frac{\eta'}{\delta}\,h_{\gamma+\varepsilon/\delta}(\delta)\,k^{\top}
\]

最后一步做了换元 t = δu，h 是第 2 节的积分写入轮廓。合起来：

\[
\boxed{\;K_t=e^{-\gamma_t\delta_t}P(\delta_t)\,K_{t-1}\Big(I-\beta_t\hat k_t\hat k_t^{\top}\Big)+w_t\,k_t^{\top},\qquad \beta_t=1-e^{-\varepsilon_t},\quad w_t=\frac{\eta'_t}{\delta_t}\,h_{\gamma_t+\varepsilon_t/\delta_t}(\delta_t)\;}
\]

写入轮廓在 Fourier 基底里逐模式是 η′ê\_0(ω)(1 − e^{−z})/z，z = ε + (γ + iω)δ，和第 2 节的闭式是同一个函数。笔者用 scipy 对原方程做高精度积分，与闭式解逐元素比较，误差在 10⁻⁹ 量级（数值积分的精度）。

**三条解读。** 第一，顺序问题消失了：擦除和写入不是先后两个动作，是同一段学习时间里的两股力量，写入轮廓的 z 里已经含了 ε，这是 Euler 离散拿不到的项。第二，重复的 key 被重新指向最近一次：每次 k 重现，右边的因子把 K 中所有指向 k̂ 方向的旧关联乘以 1 − β = e^{−ε}，ε = 3 时一次就只剩 5%，同时最新一次把 k 写在年龄零。用 k 查，返回的分布集中在最近一次出现的年龄上。小实验：A 出现四次，每次后面跟不同的 token，用 A 查后继，加性版本对最近一次的余弦 0.85、对更早的混进 0.32 和 0.23，delta 版本 1.00 和零附近。第三，剂量和时钟是两个独立的轴：δ\_t 决定这个 token 占多长的记忆时间，ε\_t 决定它覆盖多少旧绑定。ε\_t = κδ\_t 退回绑时钟的版本；δ\_t → 0 时写入轮廓 w → η′(1−e^{−ε})/ε·e\_0 是有限的，一个不占时间的 token 仍然可以更新绑定。这正是"时间定位置，Delta 定绑定"。

**关于时间分段的一条边界。** 两套时间并不意味着同一条连续 ODE 失去半群性质。如果把一个 token 的恒定驱动拆成 r 段，必须同时把每段的 δ、ε、η′ 都除以 r，连续流的复合依然精确等于原来的一步；但若只把 δ 除以 r、每段仍施加完整 ε，就变成了 r 次学习更新，不应期待不变。与此同时，δ = 0 而 ε 或 η′ 不为零时不再是 no-op：这正是时间压缩与绑定学习解耦的含义。

## 5. 为什么不擦 value

对称性会诱使人把同样的事做在 V 上：公理二的目标 Vᵀe\_0 = v\_t 也能写成最小二乘，也有梯度流。笔者一度这样做了，而且有两个版本——一个在写入头放 sink，一个沿旧绑定的轮廓擦。前者在第 8 节会看到是错的，后者有闭式解，是对的。但最后的结论是：**主模型不擦 value**。理由有四条，层层递进。

**第一，一致性自动满足。** 擦 value 时会出现一个隐藏的危险：如果 V 的某个槽被覆盖了，而 K 里指向那个槽的指针还在，key 就会自信地指向一个已经换了内容的位置——比加性存储的"糊"更糟。这其实是第三条公理：绑定被替换时，两边要一起换。V 保持加性更新，这条公理不需要任何机制去维护：没有任何操作覆盖 V 的内容，只有和 K 共享的衰减；key 侧 delta 做的是让 K 不再指向旧槽，而不是让旧槽变空。

**第二，孤儿值是无害的。** k 的旧 value 留在旧槽上，成了没人指向的孤儿。孤儿值的唯一危害是被别的查询读到，这只在另一个 token 混叠到同一个槽时发生。一圈之内每个年龄只有一个 token，不存在这种情况；跨圈的混叠由衰减或第 8 节的海绵处理。所以 value 侧擦除能清掉的东西，要么本来就没人读，要么别的机制已经清了。

**第三，收益是二阶的，附带损伤是确定的。** 擦 V 真正能改善的只有一处：softmax 不是 delta，会漏一点质量到旧绑定的槽上；K、V 同比例擦之后，漏读到的旧值污染从 (1−β) 变成 (1−β)²。ε = 3 时是 0.05 对 0.0025，差别在噪声里。而擦 V 的方向是旧绑定年龄处的带限轮廓，沿它擦会把时间上相邻的 token 一起削掉 β²D(Δ)² 的能量，D 是 Dirichlet 核，Δ 是相邻 token 的年龄差：δ = 1 时为零，δ = 0.8 时 5%，δ = 0.6 时 25%，半格时 41%。Key 侧擦除只碰语义相近的 key，那是想要的；value 侧擦除碰的是时间相邻的 token，那是不想要的。

**第四，实验看不到收益。** 第 4 节的后继实验里，只擦 K 的余弦是 1.00，加上 value 侧绑定擦除是 0.96。

于是得到一条设计原则，它恰好对应两张矩阵的分工：**地址映射用最小二乘，内容映射用叠加。** 地址必须精确，内容可以叠加。这不是权宜，是从公理和数值里推出来的。对称的版本（K、V 都擦）作为附录里的变体保留：如果一定要做，正确的形式是擦除比例与 key 侧相同 β^v = β，乘一个以 ‖K̄\_{t−1}k\_t‖ 为输入的门以避免在没有旧绑定时擦到噪声方向，并且在算这个方向之前把直流模式投掉。它只适合时钟接近整数的 head。

## 6. 读出：相对时间寻址

有了精确的地址，接下来看读出能做什么。ICL 最基本的机制是 induction head：看到当前 token A，找到它上一次出现的位置，读出当时紧跟在它后面的 token。这需要「匹配位置之后一格」。既然时间是一个坐标、P(s) 是一个群，相对时间寻址应该是读出的原生能力。

**共享的 R 为什么做不了纯平移。** CyFA 的读出是

\[
o=V^{\top}R^{\top}\mathrm{softmax}(RKq).
\]

R 同时作用在 key 分数和 value 槽上。若 R 是整数格的置换 Π，则 softmax(Πa)=Πsoftmax(a)，于是 ΠᵀΠ=I：置换在读出里抵消。这不只是置换初始化的偶然现象。令 F(a)=Rᵀsoftmax(Ra)，它是凸函数 log∑ᵢexp((Ra)ᵢ) 的梯度，因此 Jacobian 恒为对称半正定；而非平凡循环置换后的 softmax 映射 Πsoftmax(a) 的 Jacobian 一般不对称。所以对全部输入而言，无论如何训练一个**前后共享的** R，它都不能精确实现「只将读到的位置统一平移一格」。R 仍可学会非置换的局部混合；原始 CyFA 对 R 的消融收益不应被简单理解成「学到了平移」。

**把群元素放在 softmax 和 V 之间。** 我们不拆开原来的 R，也不移除它对 value 的逆变换，只在它之后增加一次物理年龄平移：

\[
o_t=V_t^{\top}\,P(-s_h)\,R^{\top}\mathrm{softmax}(RK_tq_t).
\]

先算 p=softmax(RKq)，再用 Rᵀ 恢复物理槽分布，最后让 P(−s_h) 移动读取位置。因为旧 token 在**年龄更大**的一侧，所以若 A 在年龄 a、后继 B 在年龄 a−1，查询 A 并读 B 需要 P(−1)，即按此处约定 **s_h=+1**，不是 −1。更一般地，B 的时钟增量若为 δ_B，需要 s≈δ_B。s<0 则读匹配位置之前的内容。可学习的 s 可以取分数值，不要求时钟等于整数。

当 s_h=0 时，上式对任意 R 都严格退回 CyFA。无海绵时，换到 absolute-clock 坐标，第二遍查询从 P(−τ_t)Rᵀp_t 变成 P(−τ_t−s_h)Rᵀp_t；其计算仍是 Fourier 相位加法。

这带来三个直接的研究方向：一个标量的相对偏移；用若干 s 读取匹配位置附近的一小段；让 s_t 由输入预测，询问「上次见到 X 之后某段记忆时间内发生了什么」。对于固定 s_h 的 head，可以检查训练后是否有一组偏移聚集在 0 附近、另一组聚集在正的约一格位置；但这是**待检验的预测**，不是从公式推出的必然结果。

**Previous-token key 与偏移读出互补。** 如果 q_t≈k_t，而写入与读出在同一步内按「先更新、后读取」执行，Delta 会覆盖旧的同向绑定，查询可能只找到当前 token。一个常见的 induction 实现是 previous-token key：写入时 k_t≈f(x_{t−1})、v_t≈g(x_t)，查询时 q_t≈f(x_t)。这样即使 s=0，也能直接取到 A 的后继；相对时间平移提供的是另一种、尤其适合连续与可变时钟的寻址方式。ShortConv 给模型提供前一个 token 的信息，但是否真正学到该机制仍需消融证明。

**海绵 head 需要额外小心。** P(−s) 定义的是原始物理年龄空间的平移；海绵的生成元 G=J−diag(σ) 一般与 J 不交换。因此把 s 直接加到 G 本征基的相位里，并不等于 P(−s)。可以把固定偏移的精确变换 UᵀP(−s) 预计算或融合进读出，但不能声称它在海绵 head 上仍是零额外代价的相位加法。第 9 节写出完整实现。

## 7. 哪些操作是允许的：左边与右边


在处理最后一个问题（跨圈混叠）之前，值得先把设计空间划清楚。第 4 节能精确求解，靠的是"左乘和右乘交换"。把这件事说得更一般一点：方程 dX/dτ = GX + XB + C 拉直成向量后，生成元是 Kronecker 和

\[
\mathrm{vec}(GX)=(I\otimes G)\,\mathrm{vec}X,\qquad \mathrm{vec}(XB)=(B^{\top}\otimes I)\,\mathrm{vec}X,\qquad e^{(I\otimes G)+(B^{\top}\otimes I)}=e^{B^{\top}}\otimes e^{G}
\]

两个因子永远交换。所以：

**右边（key 空间）可以放任何东西。** 随 token 变、秩一、秩多都行，它和左边永远分开求解，秩一时指数有显式表达。Delta 法则就住在这里，这是它能有闭式解的全部原因。

**左边（槽空间）要同时保住便宜的可解递归和固定坐标变换，以下是三类实用的充分条件，而非穷尽一切可能性的分类。**

| 类别 | 例子 | 为什么可行 |
| --- | --- | --- |
| (a) 与 J 交换，和位置无关 | 均匀衰减 γI、扩散 D·J² | 和输运同时在 Fourier 基底里对角化 |
| (b) 在写入头坐标系里固定，不随 token 变 | 写入头旁的吸收层 | G 固定，对角化一次 G = UΛU⁻¹，δ\_t 只通过 e^{Λδ\_t} 进入 |
| (c) 随 token 变，但在 absolute 坐标里静止 | 沿旧绑定轮廓 p̂p̂ᵀ 的擦除 | 跟着内容走，内容在 absolute 坐标里不动 |

(b) 类值得多说一句。G 不再是 Fourier 对角的，但它固定，所以可以在训练前对角化一次。Λ 的虚部给出相位，并进写入向量，和 CyFA 的 b̄\_t 做法一样；实部变成每个模式各自的衰减，是一个向量门。向量门仍是左边的对角算子，和右乘的擦除交换，所以 key 侧闭式解原样成立，只是写入轮廓逐模式变成 (1 − e^{−z\_i})/z\_i，z\_i = ε + (γ − λ\_i)δ。代价是 U 不正交，条件数要盯住。

**难以沿用同一个快速核的是：随 token 变、又固定在写入头坐标系里的非交换算子。** 例如每个 token 的 sink 强度都不同，G_t 便不一定共享本征基，不能再靠一次对角化得到本文使用的逐模式门；朴素实现需要每步施加稠密状态变换。特殊的可交换或结构化情形仍可能有其他快速算法，因此这里谈的是当前构造的计算边界，而非一般不可能定理。

这张表说明了两件事。其一，第 4 节的擦除放在右边不是巧合，内容寻址天然属于 key 空间。其二，本文希望用固定本征基高效处理跨圈混叠，因此优先选择 (a) 或 (b) 类——它关心的是"位置"（走完一圈的内容），不是"内容"。(a) 类里的扩散可以把旧内容钝化，但要用圈内精度去换；真正干净的答案在 (b) 类，也就是下一节。

## 8. 跨圈混叠：从点状 sink 到海绵层

现在回到公理二。环的周长是 m 个单位记忆时间，δ ≈ 1 的 head 在 2K 上下文里要走 16 圈，年龄 s 和 s+m 落在同一个槽上。CyFA 靠遗忘门 α 把旧圈压下去，但那是以丢掉远处内容为代价的，而且圈内和跨圈由同一个 α 控制，想让旧圈不混进来就得整体忘得快。我们想要的是：圈内全强度保留，换圈干净抹掉。

**一次失败的尝试。** 最直接的想法是在写入头放一个 sink：dV/dτ = (J − γI)V − κe\_0e\_0ᵀV + …。它的连续极限是带点状吸收的输运方程 ∂\_τf = −∂\_xf − κδ(x)f，沿轨迹积分，内容每穿过 x = 0 一次就乘以 e^{−κ}，走 n 圈是 e^{−nκ}。图像很漂亮。但数值说不。用 m = 127 的环直接算 exp((J − κe\_0e\_0ᵀ)·m)，看一个从年龄 1 出发的内容块走完一圈后还剩多少（γ = 0）：

| κ | 精确 ODE：与原位置的重叠 | 预期 e^(−κ) |
| --- | --- | --- |
| 0.5 | 0.606 | 0.607 |
| 1 | 0.357 | 0.368 |
| 2 | 0.062 | 0.135 |
| 3 | −0.109 | 0.050 |
| 8 | −0.443 | 0.000 |
| 16 | −0.589 | 0.000 |

κ ≤ 1 时图像基本对，但那只是温和的衰减；想覆盖就要 κ 大，而 κ 大时透射率反号、变大。原因是 d‖V‖²/dτ = −2κ(e\_0ᵀV)²：吸收速率正比于内容在 e\_0 方向上的分量的平方，κ 很大时这个分量被钉在零附近，吸收反而停了——sink 变成一堵墙，内容撞上去被反射，和量子 Zeno 效应是一回事。把 sink 冻结成每步一次的秩一投影也救不回来：δ = 0.9、κ = 8 时一圈后还剩 13%，δ = 0.5 时刚写入的内容下一步就被擦掉三分之一，因为相邻两步的落点轮廓重叠 0.64。

**诊断。** e\_0 不是一个点，是一个 Dirichlet 核；e\_0e\_0ᵀ 是向它的投影，不是逐点乘子。内容以每单位记忆时间一格的速度穿过 sink，每格的吸收速率一旦远大于这个穿越速率，就成了墙。所以每格的吸收只能是 O(1)；想让每圈的总吸收是 Σ，就必须把它摊到 W ≳ Σ 格上。这和数值 PDE 里的 sponge layer 是同一回事。

**海绵层。** 取固定生成元 G = J − diag(σ)，另把可变的均匀衰减 γI 独立放在外侧。σ 是一个 Hann 形状的吸收轮廓，放在最老的 W 个年龄上——紧挨在写入头后面，内容绕回写入头之前经过的最后一段。总量 Σ = Σ\_jσ\_j。它是第 7 节 (b) 类的算子：固定，对角化一次，absolute-clock 照用，key 侧闭式解照用。

*原稿此处的“环形记忆、写入头与海绵层”示意图未包含在导出文件中。*

图中内容顺着环流动，整圈保持全强度；绕回写入头之前穿过最老的 W 格，在那里被逐格吸收到 e^(−Σ)，然后才进入下一圈。

连续输运 PDE 里有一个漂亮的规范变换。令 f=gφ，g(x)=exp(−∫₀ˣσ+Σx/m)，它是周期函数；代入 ∂\_τf=−∂\_xf−σf 得到 ∂\_τφ=−∂\_xφ−(Σ/m)φ。**在连续函数空间中**，局部吸收与一个非正交坐标系里的均匀衰减等价。但带限离散的 m 维环并不是这个无限维 PDE 的精确截断：局部乘法算子与带限投影一般不交换，因此不能推出有限维 G 的所有本征值实部都严格等于 −Σ/m。

真正对任意 m 都严格成立的是迹恒等式：

\[
\frac1m\sum_{i=1}^m\operatorname{Re}(\lambda_i(G))
=\frac{\operatorname{tr}(G)}m=-\frac{\Sigma}{m}.
\]

一个可复核的例子：取 m=127、W=16，海绵在最后 16 格采用离散 Hann 窗、归一化到 Σ=3，计算 G=J−diag(σ) 的本征值，实部最小约 −0.034354、中位数约 −0.023622、最大约 −0.009458；均值精确是 −3/127≈−0.023622。条件数在这个约定下约 20.8，仍是需要注意的数值量，而 **e^Σ 只是量级直觉，不是对条件数的普适等式**。这部分支持海绵的几何解释，却也明确标出了连续极限与有限维实现之间的差别。

端到端的效果。输入是不相关的 token，约 8 圈，δ ∼ U(0.6, 1)，在每个 token 自己的年龄处读出 value，表中是"余弦 / 增益"：

| 模型 | 年龄 0–20 | 50–80 | 100–110 |
| --- | --- | --- | --- |
| CyFA，γ = 0 | 0.25 / 3.2 | 0.30 / 3.2 | 0.30 / 3.1 |
| CyFA，γ = 3/m | 0.88 / 0.91 | 0.88 / 0.26 | 0.82 / 0.10 |
| 点状 sink，κ = 3 | 0.82 / 1.17 | 0.83 / 1.18 | 0.80 / 1.14 |
| 海绵层，W = 16，Σ = 3 | 0.88 / 1.13 | 0.88 / 1.14 | 0.86 / 1.13 |

不衰减时八圈叠在一起，什么都读不出；均匀衰减在年轻的年龄上同样好，但老年龄的增益掉到 0.10，用 softmax 读出时老内容会被年轻内容的旁瓣盖住；海绵层在整圈内都保持全强度、高余弦。这就是"圈内全强度保留、换圈干净抹掉"。有了它，γ 可以调得很小。海绵定寿命。

**代价。** 海绵覆盖的 W 格通常不再适合高保真存储，W=16 时约占状态的 13%；W 取 2Σ 到 3Σ 是当前小实验支持的经验起点，而不是普适下界。走完一圈仍有约 5–6% 的残留范数，以近 Nyquist 纹波为主，所以海绵给出的是**软视界**，不是严格的有限长度缓存。非正交本征基的条件数要求仔细检验 fp32 的稳定性；Σ≤3 可以作为初始尝试，不能直接当成精度保证。K 和 V 必须使用同一个 G，才不会让地址与内容经历不同的年龄输运。海绵的基本代价仍然存在：δ≈1 的 head 大约在 m 个记忆时间单位内保留较强信号，过久的内容会显著削弱，可能损害原始 CyFA 依靠跨圈残留获得的长程能力。所以应当按 head 分配 Σ，并保留 Σ=0 的长程 head；最终得失取决于时钟能否有效压缩。

## 9. Delta-CyFA：完整更新式与实现

把三个答案合起来。每个 head 有时钟 δ_t（同 CyFA，含 stop-gradient）、遗忘速率 γ_t（α_t=e^{−γ_tδ_t}）、擦除剂量 ε_t、key/value 的连续写入强度 η′_t 与 η′ᵛ_t；另有每 head 的相对读出偏移 s_h 和固定海绵总量 Σ_h。**读出矩阵 R 仍在 key 与 value 两侧共享**，保留原始 CyFA 的基线兼容性。定义 G=J−diag(σ)，其中 Σ_h=0 的 head 有 G=J，S(δ)=e^{δG}。

对应于两套时间 ODE，更新是

\[
\boxed{K_t=e^{-\gamma_t\delta_t}S(\delta_t)K_{t-1}
(I-\beta_t\hat k_t\hat k_t^\top)+w_t^K k_t^\top,\qquad
V_t=e^{-\gamma_t\delta_t}S(\delta_t)V_{t-1}+w_t^V v_t^\top,\quad
\beta_t=1-e^{-\varepsilon_t}.}
\]

这里不在 V 上做 Delta；两侧使用**同一个**年龄输运生成元 G，但写入轮廓不同，因为只有 K 有擦除剂量 ε。

**本征坐标与精确写入。** 固定 head 的 G 若可对角化，预先计算 G=UΛU⁻¹，λ_i=ρ_i+iω_i。令 c=U⁻¹e₀，并定义稳定的函数 φ(z)=(1−e^{−z})/z，z≈0 时用 `-expm1(-z)/z` 或级数计算。逐本征模式：

\[
z_{t,i}^{K}=\varepsilon_t+(\gamma_t-\lambda_i)\delta_t,
\qquad z_{t,i}^{V}=(\gamma_t-\lambda_i)\delta_t,
\]

\[
(U^{-1}w_t^K)_i=\eta'_t c_i\,\phi(z_{t,i}^K),\qquad
(U^{-1}w_t^V)_i=\eta_t^{\prime v}c_i\,\phi(z_{t,i}^V).
\]

这就是「输运、衰减、擦除、写入同时发生」的精确解。若某个 G 难以稳定对角化，不能继续把以下表达式当成稳定的快速核，应改用实 Schur 分解或其他可靠的矩阵函数算法作为参照。

**Absolute-clock 形式。** 定义累计时钟 τ_t=Σ_{j≤t}δ_j，Θ(τ)=diag(e^{iω_iτ})，再把状态变成

\[
\bar K_t=\Theta(-\tau_t)U^{-1}K_t,\qquad
\bar V_t=\Theta(-\tau_t)U^{-1}V_t.
\]

两个递归分别变为

\[
\bar K_t=D_t\bar K_{t-1}
(I-\beta_t\hat k_t\hat k_t^\top)+\bar w_t^K k_t^\top,
\qquad \bar V_t=D_t\bar V_{t-1}+\bar w_t^V v_t^\top,
\]

\[
D_t=\operatorname{diag}\big(e^{(\rho_i-\gamma_t)\delta_t}\big),\qquad
\bar b_{t,i}=e^{-i\omega_i\tau_t}c_i.
\]

在这套坐标里，写入轮廓有两个完全等价的算法：直接用 φ，或用相邻时刻写入向量之差。后一种是

\[
\boxed{\bar w_{t,i}^{K}=\eta'_t
\frac{\bar b_{t,i}-e^{-[\varepsilon_t+(\gamma_t-\rho_i)\delta_t]}\bar b_{t-1,i}}
{\varepsilon_t+(\gamma_t-\lambda_i)\delta_t},}
\]

\[
\bar w_{t,i}^{V}=\eta_t^{\prime v}
\frac{\bar b_{t,i}-e^{-(\gamma_t-\rho_i)\delta_t}\bar b_{t-1,i}}
{(\gamma_t-\lambda_i)\delta_t}.
\]

**注意分子只能包含实数幅度衰减**：相位已经在 b̄_{t−1} 与 b̄_t 的差异里，不能再把带有 iω_i 的整个 z 放进指数，否则就重复计入了相位。对于 Σ=0 的 head，ρ_i=0，D_t 退化成标量门，K 侧递归具有 Gated DeltaNet 的形状。对于海绵 head，ρ_i 不严格相等，K、V **两遍都必须处理逐模式门**；不能只升级第一遍。

**物理槽读出。** 定义 p_t=Rᵀsoftmax(RK_tq_t)。完整读出仍是

\[
o_t=V_t^\top P(-s_h)p_t.
\]

在本征坐标里，K_t=UΘ(τ_t)K̄_t、V_t=UΘ(τ_t)V̄_t。因此第一遍的槽分数要按 UΘ(τ_t)K̄_tq_t 还原，第二遍的查询向量必须按

\[
\boxed{\bar q_t^{V}=\Theta(\tau_t)^\top U^\top P(-s_h)
R^\top\operatorname{softmax}\!\big(RU\Theta(\tau_t)\bar K_tq_t\big)}
\]

构造，输出 o_t=V̄_tᵀq̄_t^V。特别是当 U 不正交时，恢复物理分数用 U，而送入第二遍读出的转置是 Uᵀ，**不是 U⁻¹**。实数实现可以将共轭本征对表示成二维实旋转块，避免误把复数转置与共轭转置混用。

这也回答了第 6 节的实现疑问：Σ=0 时，P(−s_h) 与 P(−τ_t) 组合成一次相位偏移；Σ>0 时，一般有 [G,J]≠0，不能在 Θ 的相位里直接加 s_h。若 s_h 是固定可学习的 head 参数，可以将 UᵀP(−s_h) 融入静态读出变换；训练 s_h 时仍需保留对这一变换的梯度。实现代价要另测，不能计为一项免费加法。

**两遍内核的变化。** 结构仍然是「先求槽分数 → 物理槽 softmax → 读取 V」，但内核要按海绵 head 与无海绵 head 分开讨论：

| 阶段 | Σ=0：无海绵 head | Σ>0：海绵 head |
| --- | --- | --- |
| 第一遍：K 到槽分数 | 标量门 gated delta rule；需核对独立 ε、η′ 的参数化 | 逐模式门 gated delta rule；需支持非正交基底 |
| 中间：槽 softmax 与相对偏移 | 保留共享 R，偏移可并入 Fourier 相位 | 保留共享 R，精确应用 UᵀP(−s_h) |
| 第二遍：V 读取 | 标量门线性注意力 | 逐模式门线性注意力；不能直接沿用标量门核 |

在 Σ=0 的理想情况下，第一遍升级为 Delta 核、第二遍保持标量门，粗略估计总算时会比原始 CyFA 增加；「约 1.5 倍」只是在假设第一遍耗时翻倍、两遍原本各占一半时的**模型估计**，不是真实训练测速。海绵 head 的额外基底转换、逐模式门、数值精度及反向传播成本必须在端到端 benchmark 中单独报告。

**参数化与训练。** ε_t=softplus(W_εx_t+b_ε)，β=1−e^{−ε} 可初始化到约 0.5；η′ 分别对 K、V 设可学习的有界幅度；s_h 从 0 初始化；Σ_h 可先在 {0,1,2,3} 试不同固定配置，并保留一些 Σ_h=0 的 head。γ_t 保留 CyFA 式遗忘门的自由度，k 上的 ShortConv 提供 previous-token 特征。K、V 的 state shape 不变，但无海绵 head 和海绵 head 需要不同的运算路径。

**从 CyFA 到 Delta-CyFA。** 这个改法没有新增可随序列增长的记忆容量，核心变化是 K 侧 Delta、独立绑定剂量、可学习的相对读出，以及可选的海绵输运。这里「最小更改」成立于概念上的状态结构；工程上的核复杂度与运行时间是否足够小，是需要独立证实的研究问题。

## 10. 可证伪的预测与实验清单


推导给出的是机制，机制的价值要靠预测来兑现。每个部件各有一条能被证伪的预测：

| 部件 | 预测 | 怎么测 | 什么结果算失败 |
| --- | --- | --- | --- |
| Key 侧 delta | 重复 key 场景从崩到 GDN 水平 | MQAR 加固定模板；最近后继测试 | 曲线随 KV 对数仍然崩，或学到的 ε 收敛到 0 |
| 两套时间 | 时钟压缩模板词时仍指向最近一次 | 同上，δ 由模型学 | 压缩后的模板词分数打平 |
| 相对时间读出 | s\_h 直方图可能在 0 和正的约 1 两处成簇 | LM 训练后画 s\_h 分布；序列喂两遍三臂（previous-token key / 读出平移 / 两者） | s\_h 全部留在 0 附近，且平移臂无收益 |
| Previous-token key | q = k 时 delta 反而输给 CyFA | 序列喂两遍加 q = k 臂 | 不成立则说明自我擦除被别的机制掩盖了 |
| 海绵层 | 多针 NIAH 退化曲线变平，单针不退 | RULER MK-NIAH 2K→8K；FDA/SWDE | 单针退超过 1 分 |
| 海绵的视界 | Σ > 0 的 head 时钟会学得更压缩 | 训练后按 Σ\_h 分组看 δ 分布 | 时钟不动而召回退，说明视界被砍了 |
| 连续流的分段一致性 | 同一恒定输入驱动下，精确离散与步长划分无关 | oracle 将单个 token 的 δ、ε、η′ **同时**除以 r，并重复积分 r 次对拍 | 精确实现不一致（单独缩放 δ 的测试不属于同一流） |

**在 benchmark 上的预期。** 说实话，不是全面碾压，是分战场。Key 侧 delta 的 headline 是 few-shot 组——CyFA 在 TREC 上 32.5、KDA 47.5，机制直接对应，预期 +5 到 +10；LAMBADA 应该略好，代码补全略好。海绵的 headline 是 RULER 多针曲线的斜率和长度外推。召回套件 FDA/SWDE 是否决项：那里 key 多半不重复，delta 退化成加性写入，任务只有一个——不退。常识任务无关。核时间的 1.5 倍只是无海绵路径的粗略假设，是否与 KDA 同一量级须实测；等时间的对比表必须有。

**阶梯。** 消融按部件逐个加：CyFA → 加积分写入 → 加 key 侧 delta（剂量独立）→ 加读出偏移 → 加海绵。每一级和上一级配对比较，同一份数据、同一顺序、同一初始化。另加两个反面对照放在表里，因为审稿人会自己想到：剂量绑时钟的版本（第 4 节的冲突），以及 key 侧 delta 加点状 sink 的版本（第 8 节中连续图像和离散结果冲突的反面对照）。

100M 的合成任务一周能把前四行定性；400M 只跑三个配置：CyFA、主模型、主模型加海绵。

## 11. 文章小结

本文从一个问题出发：一个按时间组织的记忆应该遵守什么规律。三条公理给出三个答案。

**时间分段一致性**给出指数衰减和积分写入，CyFA 是它的一阶 Euler 近似；由此得到的差分公式让精确写入没有额外成本。

**召回公理一**给出 key 侧的 delta 法则。把擦除、输运、衰减、写入放进同一个方程，因为输运作用在槽空间、擦除作用在 key 空间，两者交换，方程有精确解：

\[
K_t=e^{-\gamma_t\delta_t}P(\delta_t)\,K_{t-1}\Big(I-\beta_t\hat k_t\hat k_t^{\top}\Big)+w_t\,k_t^{\top},\qquad \beta_t=1-e^{-\varepsilon_t}
\]

擦除剂量 ε\_t 必须独立于时钟 δ\_t——绑在一起会让时钟压缩模板词时丢掉"指向最近一次"的性质。Value 侧不擦：地址用最小二乘，内容用叠加，这个分工是推出来的，不是选的。

**召回公理二**要求换圈时旧内容让位。点状 sink 在带限环上会产生类似 Zeno 反射的现象；将吸收摊到有宽度的海绵层，是数值模拟支持的一条解决路线。连续 PDE 里它经规范变换等价于均匀衰减；有限维环里本征实部仍有离散，必须保留逐模式门。它产生的是可调节的软视界，因此 Σ 要按 head 分配。

读出端，时间作为坐标应该支持相对寻址：CyFA 前后共享的 R 无法精确实现纯位置平移；在 Rᵀ 与 V 之间增加 P(−s)，便能独立表达这一操作。按本文的年龄方向，读取匹配 token 的后继对应 s>0；有海绵时还必须保留物理平移与本征相位的区别。

把这些合起来，Delta-CyFA 对 CyFA 的概念性改动是：key 侧的 Delta 更新、独立剂量门、一个相对时间偏移，以及可选的吸收层。没有扩大状态维度；但带海绵的 head 在两个递归核和相对读出上都有真实实现成本。一句话：**时间定位置，Delta 定绑定，海绵定寿命。**

最后说一句方法。这篇文章里每一项都是从一条要求推出来的，推出来的东西有一次是错的（点状 sink），错在一个漂亮的连续极限图像在带限的离散环上不成立。正因为每一项都有解释，错的地方才能被几秒钟的数值实验抓出来，而不是在几天的训练之后。效果好不好，要留给训练实验；但推导已经把"哪里可能赢、哪里不可能赢"说清楚了，这本身就是推导的价值。
